# 프로젝트 개요

이 프로젝트는 사용자가 지정한 지역 내의 모든 떡집을 검색하여 상호, 주소, 전화번호를 포함한 목록을 제공하는 웹 애플리케이션입니다.

## 핵심 기능

-   **지역 기반 검색:** 사용자는 텍스트 입력 필드에 지역명(예: "강남구")을 입력하여 해당 지역의 떡집을 검색할 수 있습니다.
-   **업체 정보 목록:** 검색 결과는 각 떡집의 상호, 주소, 전화번호를 포함하는 명확하고 읽기 쉬운 목록으로 표시됩니다.
-   **포괄적인 데이터:** 카카오맵과 같은 외부 지도 서비스 API와 연동하여 누락 없는 최신 업체 정보를 제공하는 것을 목표로 합니다.

## 기술 스택

-   **프론트엔드:** HTML, CSS, JavaScript (프레임워크 없이 순수 기술 사용)
-   **데이터 소스:** 카카오맵 키워드 검색 API (연동 필요)

## API 연동 계획

현재 애플리케이션은 샘플(mock) 데이터로 작동하도록 구현되어 있습니다. 실제 실시간 데이터를 가져오려면 다음 단계가 필요합니다.

1.  **카카오 개발자 등록 및 앱 생성:** [카카오 개발자 사이트](https://developers.kakao.com/)에서 개발자로 등록하고 새 애플리케이션을 생성합니다.
2.  **플랫폼 등록:** 생성된 애플리케이션에 Web 플랫폼을 추가하고, 애플리케이션을 실행할 사이트 도메인(예: `http://localhost:8080`)을 등록합니다.
3.  **API 키 발급:** 앱의 요약 정보에서 `JavaScript 키`를 복사합니다.
4.  **코드에 API 키 적용:** `main.js` 파일 내에 지정된 위치(`YOUR_KAKAO_API_KEY`)에 발급받은 JavaScript 키를 붙여넣습니다.

이 과정을 거치면 애플리케이션이 카카오 API와 연동되어 실제 떡집 데이터를 검색하고 표시하게 됩니다.

## 현재 변경 요청 계획

1.  `index.html`: 검색 UI (입력창, 버튼) 및 결과 표시 영역 추가
2.  `style.css`: 애플리케이션 레이아웃 및 디자인 개선
3.  `main.js`:
    -   검색 버튼에 대한 이벤트 리스너 추가
    -   카카오맵 API 연동을 위한 함수 구조 및 주석 가이드 작성
    -   UI에 결과를 동적으로 렌더링하는 기능 구현
    -   기능 시연을 위한 샘플 데이터 포함
4.  GitHub 푸시: 모든 변경 사항을 원격 저장소에 커밋 및 푸시
